Terms of Use

rclone Workspace Sync is a private utility operated solely for the owner's personal file synchronization.

Permitted use

The utility may be used only by the owner to transfer selected workspace files between the owner's devices and the owner's Google Drive. It is not offered as a hosted service to other users.

Account and data control

The owner remains responsible for the Google account, local devices, file selection, backups, and revoking OAuth access when it is no longer needed. The utility requests the limited drive.file scope.

No warranty

The utility is provided as-is for personal use. Important files should have an independent backup before synchronization or configuration changes.
