Private utility

rclone Workspace Sync

A personal utility that moves selected workspace files between the owner's computers through a dedicated folder in the owner's Google Drive.

Limited Drive access

The utility requests the Google Drive drive.file scope. It can access only files that it creates or that the owner explicitly opens with it. It does not request access to the owner's entire Drive.

How it operates

  • It is used only by the owner on the owner's Windows and Linux hosts.
  • OAuth credentials remain in private configuration on those hosts.
  • This website uses no analytics, cookies, accounts, or tracking scripts.
